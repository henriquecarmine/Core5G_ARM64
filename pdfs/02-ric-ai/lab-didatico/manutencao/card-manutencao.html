📖 O que é classificação?

Pense numa triagem: olhar os sintomas e dizer a categoria. Classificação é isso — escolher um rótulo (não um número).

Aqui as pistas são KPIs da célula e a resposta é as classes. No O-RAN vira um xApp que, sabendo o estado, deixa o RIC agir.

🔬 Aprofundar: como a Regressão Logística decide

Ela soma os KPIs com pesos e passa por uma curva em “S”, virando uma probabilidade para cada classe — a mais provável vence. Interpretável: dá pra ver qual KPI puxou o resultado.

Regressão Logística — a fórmula e o código

O que o modelo captura (aprende no fit) e o que retorna depois.

A ideia, passo a passo (sem jargão)
  1. Soma os KPIs com pesos, igual à regressão: s = β₀ + β₁·KPI₁ + …
  2. Uma curva em “S” espreme esse número entre 0 e 1 → vira uma probabilidade.
  3. Com várias classes, o softmax dá uma probabilidade para cada (somando 100%).
  4. Vence a classe de maior probabilidade.
  5. O treino ajusta os pesos até as probabilidades baterem com os rótulos reais.
As variáveis, uma a uma
sa pontuação — a soma ponderada dos KPIs (igual à regressão): s = β₀ + β·KPIs.
βos pesos por classe — cada classe tem seu jogo de pesos; o KPI que “puxa” para Congestionada tem β alto nela.
σ(s)a curva em “S” (sigmoide) — espreme a pontuação para o intervalo 0–1, virando probabilidade.
softmaxo rateio — com 3+ classes, transforma as pontuações em probabilidades que somam 100%.
P(classe)a resposta — a probabilidade de cada classe; vence a maior.
tipoequação linear + função de achatamento (sigmoide/softmax)
serve p/transformar KPIs em probabilidade de categoria — com direito a “quão confiante estou”
O código Python (scikit-learn)
from sklearn.linear_model import LogisticRegression model = LogisticRegression().fit(X, y) # captura: os pesos de cada classe model.predict_proba(X_nova) # retorna: a probabilidade de cada classe model.predict(X_nova) # retorna: a classe vencedora
■ captura = fit (aprende dos dados)■ retorna = o resultado (probabilidades, classe)
