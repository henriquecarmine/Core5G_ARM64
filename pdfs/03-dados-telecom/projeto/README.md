# projeto/ — projeto integrador (50%)

Implementação do projeto integrador da disciplina: **pipeline reprodutível sobre
telemetria RAN** (caso UE-TP / load-anomaly, trilha offline).

Entram aqui, conforme o projeto evoluir:

- briefing e tema do grupo (PDFs/notas do docente: `docs/briefing-projeto.md` e
  `docs/temas-grupos.md` do lab dele);
- ETL e análise (scripts/notebooks) sobre os artefatos KPM
  (`kpm_*.log` → JSONL/SQLite);
- os ≥2 KPIs/KQIs, visualizações e a recomendação / política A1 em dry-run;
- limitações declaradas (o que o lab prova e o que **não** afirma) e material da
  apresentação/defesa (Aula 06, 29/08/2026).

Progressão: caso (A02) → Checkpoint 1 EDA (A03) → Checkpoint 2 indicadores (A04)
→ checkpoint técnico (A05) → defesa (A06). Rubrica no
[README da disciplina](../README.md).
