🗂️ Base de dados

📖 O que é clustering?

Imagine uma pilha de roupa para separar em grupos parecidos — sem ninguém dizer as categorias. Você junta o que é semelhante. Clustering é isso: achar grupos nos dados sem rótulo.

Aqui cada ponto é uma célula (throughput, PRB, energia…). O modelo as agrupa por semelhança — ex.: “células grandes e cheias” vs “pequenas e ociosas”. No O-RAN isso perfila a rede para o operador decidir onde investir ou economizar.

🔬 Aprofundar: como o k-means agrupa

Escolhe k centros, coloca cada célula no centro mais próximo, recalcula os centros como a média do grupo, e repete até estabilizar. A silhueta (−1 a 1) mede se os grupos estão bem separados: quanto mais perto de 1, melhor.

Antes de seguir:

k-means — a fórmula e o código

O que o modelo captura (aprende no fit) e o que retorna depois.

A ideia, passo a passo (sem jargão)
  1. Escolhe k pontos como “centros” iniciais.
  2. Cada célula vai para o centro mais próximo (distância).
  3. Recalcula cada centro = a média das células do seu grupo.
  4. Repete os passos 2 e 3 até os grupos pararem de mudar.
  5. A silhueta (−1 a 1) diz se os grupos ficaram bem separados.
As variáveis, uma a uma
ko nº de grupos — você escolhe; a silhueta ajuda a decidir (aqui k=3).
centroₖa “célula média” do grupo k — o perfil que o modelo descobriu (recalculado a cada rodada).
‖x − c‖a distância — a régua que decide o grupo: cada célula vai para o centro mais próximo.
silhuetaa nota da separação — de −1 a 1: mede se cada célula está mais perto do próprio grupo que do vizinho.
tipoalgoritmo iterativo por distância (não é uma equação fechada: chuta centros → agrupa → recalcula → repete)
serve p/descobrir grupos sem rótulo — perfilar células parecidas para o operador decidir
O código Python (scikit-learn)
from sklearn.cluster import KMeans km = KMeans(n_clusters=3).fit(X) # captura: onde ficam os centros dos grupos km.cluster_centers_ # retorna: a posição de cada centro km.predict(X_nova) # retorna: em qual grupo a célula cai
■ captura = fit (aprende dos dados)■ retorna = o resultado (centros, grupo)
