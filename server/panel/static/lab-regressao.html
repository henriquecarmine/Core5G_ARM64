📖 O que é regressão?

Imagine prever a nota de um aluno pelas horas que estudou: você vê vários casos, percebe o padrão e traça a linha que melhor resume. Regressão é isso — aprender a relação entre números e prever um número novo.

Aqui o número previsto é o alvo da rede, a partir dos KPIs (features). No O-RAN é um rApp/xApp que antecipa esse valor para o RIC agir.

Regressão Linear — a fórmula e o código

O que o modelo captura (aprende no fit) e o que retorna depois.

A ideia, passo a passo (sem jargão)
  1. Cada previsão é uma soma com pesos: ŷ = β₀ + β₁·KPI₁ + β₂·KPI₂ + …
  2. O erro é o quanto errou: (real − previsto)², somado em todos os exemplos.
  3. O treino acha os pesos que deixam esse erro o menor possível (os “mínimos quadrados”).
  4. Existe uma conta fechada que resolve isso de uma vez — sem tentativa e erro.
  5. Para prever: pega os KPIs novos, multiplica pelos pesos e soma. Pronto.
As variáveis, uma a uma
ŷo palpite — o valor que o modelo prevê (aqui: throughput, em Mbps). O chapéu ^ marca “previsto”, não medido.
β₀o ponto de partida (intercepto) — o valor quando todos os KPIs valem zero. Na base UE-TP: 11,9.
βⱼo peso do KPI j — quanto o alvo muda quando esse KPI sobe 1 unidade. Ex.: β dos usuários = 0,82 → cada usuário a mais ≈ +0,82 Mbps.
xⱼo KPI medido — o que a rede reporta: usuários ativos, SINR, PRB…
erroreal − previsto — o quanto errou em cada exemplo; o treino minimiza a soma dos erros ao quadrado.
tipoequação linear — uma soma ponderada (a mais simples que existe)
serve p/prever um número novo a partir de KPIs medidos — e ler o efeito de cada um
O código Python (scikit-learn)
from sklearn.linear_model import LinearRegression model = LinearRegression().fit(X, y) # captura: os pesos de cada KPI + o ponto de partida model.coef_, model.intercept_ # retorna: quanto cada KPI pesa model.predict(X_nova) # retorna: a previsão do número (ex.: throughput)
■ captura = fit (aprende dos dados)■ retorna = o resultado (pesos, previsão)
