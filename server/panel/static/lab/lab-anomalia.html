🗂️ Base de dados

📖 O que é detecção de anomalia?

É achar a peça fora do lugar — a célula que se comporta diferente de todas as outras. Sem ninguém dizer o que é “defeito”: o modelo aprende o padrão comum e sinaliza os outliers.

Aqui cada ponto é uma célula. As vermelhas destoam (throughput/energia/latência estranhos) → candidatas a falha. No O-RAN é um rApp de manutenção preditiva: pegar o problema antes de virar queda.

🔬 Aprofundar: como o Isolation Forest isola

Ele corta os dados ao acaso, repetidamente. Um ponto normal está no meio da multidão e precisa de muitos cortes para ser isolado; um outlier fica sozinho e é separado com poucos cortes. Quanto mais fácil de isolar, mais anômalo. (No “Mexe”, para rodar no navegador, medimos o quão longe da massa normal a célula está — mesmo princípio, calibrado com o Isolation Forest.)

Isolation Forest — a fórmula e o código

O que o modelo captura (aprende no fit) e o que retorna depois.

A ideia, passo a passo (sem jargão)
  1. Corta os dados ao acaso, muitas vezes (monta várias “árvores”).
  2. Conta quantos cortes para deixar cada ponto sozinho.
  3. Ponto normal está no meio da multidão → precisa de muitos cortes.
  4. Outlier fica isolado com poucos cortes → é anomalia.
  5. contamination diz quantos % você espera que sejam anômalos.
As variáveis, uma a uma
cortesas divisões aleatórias — cada árvore corta os dados ao acaso, várias vezes.
profundidadequantos cortes até isolar — ponto normal exige muitos; outlier se isola com poucos.
scorea nota de anomalia — média entre as árvores: quanto mais fácil isolar, mais anômala.
contaminationa sensibilidade — a fração de anomalias que você espera (0,05–0,15 aqui); define o limiar.
limiara régua final — acima dela, anômala. No lab, calibrado na distância padronizada (ex.: 2,73).
tipofloresta de árvores aleatórias (um comitê que vota)
serve p/apontar o fora-do-padrão sem rótulo — manutenção preditiva antes da queda
O código Python (scikit-learn)
from sklearn.ensemble import IsolationForest iso = IsolationForest(contamination=0.1).fit(X) # captura: como é o “normal” iso.predict(X) # retorna: 1 = normal, −1 = anomalia iso.decision_function(X) # retorna: o score (quão anômala)

No “Mexe”, para rodar no navegador, usamos a distância ao normal — o mesmo princípio, calibrado com este Isolation Forest.
