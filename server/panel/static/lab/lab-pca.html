PCA: resumir muitos KPIs em poucos

Redução de dimensionalidade, com o dataset do Prof. Tesolin. Quando os KPIs andam juntos, o PCA os comprime em poucas “direções” que guardam quase toda a informação.

📖 O que é PCA?

Imagine resumir um relatório de 50 páginas em 3 frases que guardam o essencial. PCA é isso para dados: acha poucas “direções” (componentes) que capturam o máximo de variação dos KPIs.

Aqui os KPIs da célula (throughput, energia, usuários…) sobem e descem juntos — célula grande tem tudo alto. Então uma única direção (PC1) já resume quase tudo. Serve para visualizar, comprimir e acelerar outros modelos.

Antes de seguir:

PCA — a fórmula e o código

O que o modelo captura (aprende no fit) e o que retorna (no transform/atributos).

A matemática, em 5 passos
  1. Padroniza cada KPI para a mesma escala: z = (x − μ) / σ.
  2. Covariância entre os KPIs: C = (1/n) ZᵀZ — quem varia junto com quem.
  3. Autovetores de C = as componentes principais (as direções de maior variância).
  4. Projeta cada célula nessas direções: Y = Z · W (W = top-k autovetores).
  5. Variância explicada de cada PC: λᵢ / Σλ — o quanto ela “resume”.
As variáveis, uma a uma
zo KPI padronizado — z = (x − μ)/σ: tira a unidade e põe tudo na mesma escala.
W (loadings)os pesos da direção — quanto cada KPI entra em cada componente (a “receita” da mistura).
PC1, PC2as novas réguas — direções que capturam o máximo da variação; projetamos as células nelas.
λ (variância)quanto cada PC resume — aqui a PC1 sozinha guarda ~97% da informação.
tipoálgebra linear — uma rotação dos eixos (autovetores da matriz de covariância)
serve p/comprimir muitos KPIs em 1–2 números e visualizar a estrutura escondida
O código Python (scikit-learn)
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

Z = StandardScaler().fit_transform(X)   # captura: μ e σ de cada KPI → padroniza
pca = PCA(n_components=2).fit(Z)         # captura: as direções de maior variância
Y = pca.transform(Z)                     # retorna: cada célula em (PC1, PC2)
pca.explained_variance_ratio_            # retorna: quanto cada PC resume (ex.: 97%, 2.5%)
pca.components_                          # retorna: o peso de cada KPI em cada PC
■ captura = fit (aprende dos dados)■ retorna = transform / atributos (o resultado)

Nesta base, explained_variance_ratio_ deu — na PC1: os KPIs andam tão juntos que quase tudo cabe em um número.
